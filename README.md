# Help & Solutions — sitio web

Sitio estático de [Help & Solutions](https://help-and-solutions.com), alojado en GitHub Pages.

## Estructura

- `index.html` — página principal (una sola página: hero, servicios, principios, nosotros, contacto)
- `politica-datos.html` — Política de Tratamiento de Datos Personales (Ley 1581 de 2012 / Decreto 1377 de 2013)
- `css/styles.css` — estilos (Material Design, paleta azul → morado → dorado del logo)
- `js/main.js` — traducciones ES/EN (español por defecto), menú móvil, animaciones
- `assets/` — logos

## Pendientes por reemplazar

1. **Número de WhatsApp**: en `index.html`, buscar `wa.me/573000000000` y reemplazar por el número real (código de país + número, sin espacios ni `+`).
2. **NIT y dirección**: en `politica-datos.html`, buscar `[PENDIENTE` / `[PENDING` y completar los datos (aparecen en la versión en español y en inglés).

## Idiomas

Español por defecto. El botón `EN`/`ES` de la barra de navegación cambia el idioma y la preferencia se guarda en el navegador.
